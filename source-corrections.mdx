Before the first publication on 2026-11-10, every page of the original Pagsmile Open API document package was checked against the Pagsmile Open API source code. This page keeps the full record: 193 corrections where the original text did not match the code, and 423 additions where the original left out a rule that the code enforces.

<Note>
  The corrected text is the wording published on 2026-11-10. Pages were rewritten on 2026-11-11, so the current wording can differ. Later changes are listed in the [documentation changelog](/changelog).
</Note>

## How to read an entry

Each entry starts with its ID, the type of change and the place in the original page. **Original** is the text of the original document package. **Corrected** is the text that was published instead.
