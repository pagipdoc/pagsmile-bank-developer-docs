Use este guia para cadastrar sua conta Pagsmile e enviar sua primeira consulta de conta assinada. Configure o acesso à Open API antes de chamar a API.

Use o canal de cadastro indicado para sua integração. As capturas de tela ilustram o cadastro, a verificação e a ativação da conta.

Siga o formulário atual para documentos, verificações e instruções de ativação. As capturas não definem critérios de aprovação nem a validade dos códigos de verificação.

## Habilitar o acesso à API

Entre no [portal Banking](https://banking.pagsmile.com.br/login) e confira a conta que você usará na integração.

<Steps>
  <Step title="Configurar o MFA da conta">
    Abra **Settings**, depois **Security**, e selecione **Set Up Account MFA**. Siga as instruções para vincular o autenticador da conta.

    O MFA da conta é obrigatório para habilitar o acesso à Open API ou gerenciar chaves de API.

    <Frame caption="Configurar o MFA da conta em Settings">
      <img src="/images/quickstart/account-mfa-setup-in-settings.png" alt="Configurar o MFA da conta em Settings" />
    </Frame>
  </Step>
  <Step title="Habilitar a Open API">
    Abra **Chaves API** (**API Keys**). Em **Credenciais da conta bancária** (**Bank Account Level Credentials**), habilite **API Aberta** (**Open API**) e informe o código solicitado pelo autenticador.

    O controle fica disponível para o titular de uma conta CNPJ. Se você não tiver acesso, peça à Pagsmile que confirme a configuração da conta.

    <Frame caption="Informar o código do autenticador para habilitar a Open API">
      <img src="/images/quickstart/enter-your-google-authenticator-code-to-enable-ope.png" alt="Informar o código do autenticador para habilitar a Open API" />
    </Frame>
  </Step>
  <Step title="Criar e salvar suas credenciais ACCOUNT">
    Em **Credenciais da conta bancária** (**Bank Account Level Credentials**), confira a conta selecionada e selecione **Ativar chave de acesso** (**Enable Access Key**). Conclua a confirmação por MFA.

    Salve a chave de acesso (AK) e a chave secreta (SK) em local seguro. Envie a AK em `X-Client-ID`; mantenha a SK no servidor para assinar requisições. O painel mostra as chaves uma única vez. Para testar requisições nesta documentação, informe-as em [Configurar acesso à API](/pt-br/api-access-setup).

## Enviar sua primeira requisição assinada

Use `POST /v3/bank_account` para consultar a conta-alvo. Envie o objeto JSON vazio `{}`; o corpo da requisição não tem campos de negócio.

<Tabs>
  <Tab title="ACCOUNT" icon="building-columns">
    Use a AK/SK de uma credencial ACCOUNT na primeira chamada. A credencial define a conta, por isso os exemplos abaixo omitem os cabeçalhos de seleção de conta.

    Mantenha esses cabeçalhos omitidos ao executar os exemplos ACCOUNT abaixo.
  </Tab>
  <Tab title="USER" icon="user">
    Selecione uma conta do USER com `X-ISPB` e `X-Account-Number`. Inclua os dois cabeçalhos na assinatura.

    Os exemplos abaixo não incluem esses cabeçalhos. Use a [ferramenta de assinatura](/pt-br/environments-and-credentials#assinar-requisições) para assinar uma requisição USER.
  </Tab>
  <Tab title="PLATFORM" icon="server">
    <Warning>Credenciais PLATFORM não podem chamar este endpoint. Use credenciais ACCOUNT ou credenciais USER com uma conta autorizada.</Warning>
  </Tab>
</Tabs>

<Steps>
  <Step title="Escolher o ambiente e as credenciais">
    Comece com credenciais configuradas para o Sandbox. A URL base do Sandbox é `https://ebanking-openapi-sandbox.pagsmile.com.br`.

    A URL base de produção é `https://ebanking-openapi.pagsmile.com.br`. Confira o ambiente selecionado antes de enviar uma requisição.
  </Step>
  <Step title="Preparar o exemplo">
    Defina `PAGSMILE_AK` e `PAGSMILE_SK` no ambiente do servidor. Os exemplos usam o Sandbox por padrão; `PAGSMILE_BASE_URL` substitui a URL base. [Configurar acesso à API](/pt-br/api-access-setup) gera essas variáveis para bash e PowerShell.

    Use o ambiente de execução indicado na aba da linguagem. Não incorpore credenciais ao código do navegador, ao controle de versão ou a mensagens de suporte.
  </Step>
  <Step title="Assinar e enviar os mesmos bytes">
    Assine o caminho, os cabeçalhos obrigatórios e o corpo exato da requisição com HMAC-SHA256. Não reformate o JSON depois de assinar.

    Use novos `X-Nonce` e `X-Timestamp` a cada tentativa, inclusive após um erro de assinatura. Confira o IP do servidor na lista de permissões.

    Use a [ferramenta de assinatura](/pt-br/environments-and-credentials#assinar-requisições) para conferir uma requisição antes de enviar.
  </Step>
  <Step title="Interpretar o resultado de negócio">
    Leia `code` antes de usar `data`. Quando `code` é `200`, a consulta da conta funcionou; isso não comprova a conclusão de um pagamento.

    Todo resultado de negócio em JSON retorna HTTP 200, inclusive erros. Um corpo ilegível ou JSON inválido retorna HTTP 400 com texto simples.

    Veja [Dados da conta](/pt-br/api-reference/accounts/get-account-balance) para os campos retornados e [Erros de autenticação](/pt-br/api-reference/error-catalog#erros-de-autenticação) para requisições recusadas.

    Inclua o cabeçalho de resposta `xxx-log-id` nas solicitações de suporte, sem sua SK nem as credenciais completas.
  </Step>
</Steps>

Escolha uma linguagem. Cada exemplo assina e envia o mesmo corpo `{}`, inclui `X-Content-Hash` e exibe a resposta.

Defina `PAGSMILE_TIMEOUT_SECONDS` como um inteiro positivo; os exemplos usam 30 segundos por padrão. No Python, o timeout vale para operações bloqueantes de socket; nos demais exemplos, limita a duração total da requisição.

Falhas de conexão e timeouts são exibidos na saída de erro e encerram o programa com erro, separadamente dos resultados de negócio em JSON. Os exemplos não repetem a requisição automaticamente.

<CodeGroup>

```bash cURL
# Requer curl, OpenSSL e Python 3. Exporte PAGSMILE_SK; o auxiliar HMAC lê a chave do ambiente, nunca dos argumentos de linha de comando. Defina PAGSMILE_AK e PAGSMILE_SK. PAGSMILE_BASE_URL usa o Sandbox por padrão.
BASE_URL="${PAGSMILE_BASE_URL:-https://ebanking-openapi-sandbox.pagsmile.com.br}"
REQ_PATH="/v3/bank_account"
TIMEOUT_SECONDS="${PAGSMILE_TIMEOUT_SECONDS:-30}"
case "$TIMEOUT_SECONDS" in
  ''|*[!0-9]*|0*) echo 'PAGSMILE_TIMEOUT_SECONDS must be a positive integer' >&2; exit 1 ;;
esac
BODY='{}'

# Assine exatamente os bytes enviados. Use novos nonce e timestamp a cada tentativa.
TS=$(( $(date +%s) * 1000 ))
NONCE=$(openssl rand -hex 16)
HASH=$(printf '%s' "$BODY" | openssl dgst -sha256 -hex | sed 's/^.* //')
STRING_TO_SIGN=$(printf 'POST\n%s\n\ncontent-type:application/json\nx-client-id:%s\nx-content-hash:%s\nx-nonce:%s\nx-timestamp:%s\n%s\n%s\n%s' \
  "$REQ_PATH" "$PAGSMILE_AK" "$HASH" "$NONCE" "$TS" "$HASH" "$TS" "$NONCE")
SIGNATURE=$(printf '%s' "$STRING_TO_SIGN" | python3 -c 'import hashlib, hmac, os, sys; print(hmac.new(os.environ["PAGSMILE_SK"].encode("utf-8"), sys.stdin.buffer.read(), hashlib.sha256).hexdigest())')
```

```go Go
	if baseURL == "" {
		baseURL = "https://ebanking-openapi-sandbox.pagsmile.com.br"
	}
	path := "/v3/bank_account"
	ak, sk := os.Getenv("PAGSMILE_AK"), os.Getenv("PAGSMILE_SK")
	timeoutSeconds := 30
	if value := os.Getenv("PAGSMILE_TIMEOUT_SECONDS"); value != "" {
		var err error
		timeoutSeconds, err = strconv.Atoi(value)
		if err != nil || timeoutSeconds <= 0 {
			fmt.Fprintln(os.Stderr, "PAGSMILE_TIMEOUT_SECONDS must be a positive integer")
			os.Exit(1)
		}
	}
	client := &http.Client{Timeout: time.Duration(timeoutSeconds) * time.Second}

	body := []byte(`{}`)

	// Assine exatamente os bytes enviados. Use novos nonce e timestamp a cada tentativa.
	ts := strconv.FormatInt(time.Now().UnixMilli(), 10)
	nb := make([]byte, 16)
	rand.Read(nb)
	nonce := hex.EncodeToString(nb)
	sum := sha256.Sum256(body)
	contentHash := hex.EncodeToString(sum[:])
	stringToSign := strings.Join([]string{
		"POST", path, "",
		"content-type:application/json",
		"x-client-id:" + ak,
		"x-content-hash:" + contentHash,
		"x-nonce:" + nonce,
		"x-timestamp:" + ts,
		contentHash, ts, nonce,
	}, "\n")
	mac := hmac.New(sha256.New, []byte(sk))
	mac.Write([]byte(stringToSign))
	signature := hex.EncodeToString(mac.Sum(nil))

	req, err := http.NewRequest("POST", baseURL+path, bytes.NewReader(body))
	if err != nil {
		fmt.Fprintln(os.Stderr, "Transport failure:", err)
		os.Exit(1)
	}
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("User-Agent", "your-app/1.0")

	req.Header.Set("X-Timestamp", ts)
	req.Header.Set("X-Nonce", nonce)
	req.Header.Set("X-Content-Hash", contentHash)
	req.Header.Set("X-Signature", signature)

		fmt.Fprintln(os.Stderr, "Transport failure:", err)
```
