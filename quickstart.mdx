## Enable API access

After your production account has been opened and activated, use **Developer Center** in the [Banking portal](https://banking.pagsmile.com.br/login) to access your Sandbox test account.

<Info>
  These steps describe the upcoming Developer Center workflow. Follow them when **Developer Center** is available in your Banking portal.
</Info>

<Steps>
  <Step title="Open Developer Center">
    Sign in to the Banking portal with your production login, then select **Developer Center** in the sidebar. Open **Overview** and check the **Sandbox** label and the test account shown there.

    The Sandbox account is for API use and has no separate portal login. Sandbox operations in Developer Center do not require MFA, a payment password, or another verification code. Your Banking sign-in requirements still apply.
  </Step>
  <Step title="Wait for your test account to be ready">
    Pagsmile automatically prepares a Sandbox test account and its ACCOUNT access key (AK) and secret key (SK) after production account activation. You do not need to create another account or generate the initial key pair.

    If preparation is still in progress, return to **Overview** later. If it fails, follow the recovery action shown there. Check the displayed test account before continuing; switching production accounts does not reassign the test credentials.
  </Step>
  <Step title="Allow Sandbox API access">
    Open **Test credentials**. The primary member can select **View and copy credentials** and confirm that the credential is **Enabled**.

    Under **IP allowlist**, add the public outbound IP for each place you will test:

    - **Developer Center in the Banking portal:** add your current computer's public outbound IP to the Sandbox API allowlist before testing.
    - **Your server:** add the server's public outbound IP before sending API requests from your integration.

    If you use a VPN or company network, allow the public IP through which your test traffic leaves that network. Do not enter your computer's private LAN address. Check the IP again if you change networks or VPN connections.

    Follow [Set up API access](/api-access-setup) to save the Sandbox key pair, find the correct IP, and configure your server. That page also provides optional Sandbox credential entry and testing in these docs.

    If your team account cannot manage credentials, ask the primary member to complete this step. Sandbox credentials can be viewed again later without rotating them.
  </Step>
</Steps>

## Explore APIs in Developer Center

Before testing, confirm that your current computer's public outbound IP is saved under **Test credentials → IP allowlist** for the Sandbox API.

In **Overview**, find **Test your integration**. Select **Accounts and funds** in **Integration scenario**, then select **Test in sandbox** for `POST /v3/bank_account`.

The form reads the request fields and examples from the API documentation and fills in the test account context. This account query uses the body `{}`. For other operations, review example values and provide the business fields needed for your test. You can inspect the request as a form or JSON.

A response labeled as an example or simulation does not prove that an API request succeeded. Even a successful request from Developer Center does not verify your server's IP or signing code. Continue below to check your own integration.

## Send your first signed request

Send `POST /v3/bank_account` from your server to retrieve the Sandbox test account. Use the ACCOUNT key pair from **Test credentials** and the empty JSON object `{}`.

The credential selects the account, so the examples omit `X-ISPB` and `X-Account-Number`. If your integration uses separately provisioned USER credentials, follow [Credentials and account selection](/environments-and-credentials#credentials-and-account-selection) instead. PLATFORM credentials cannot call this endpoint.

<Steps>
  <Step title="Confirm the Sandbox target">
    Use `https://ebanking-openapi-sandbox.pagsmile.com.br` and the Sandbox ACCOUNT key pair. Confirm that your server's outbound IP is on that credential's allowlist.

    The Production base URL, `https://ebanking-openapi.pagsmile.com.br`, is shown for reference only. Credential entry and online testing in these docs are Sandbox only.
  </Step>
  <Step title="Prepare the sample">
    Set `PAGSMILE_AK` and `PAGSMILE_SK` in your server environment. The examples default to Sandbox; if you set `PAGSMILE_BASE_URL`, keep the Sandbox URL for this guide. [Set up API access](/api-access-setup) generates these variables for bash and PowerShell.

    Use the runtime shown in your language tab. Do not put credentials in browser code, source control or support messages.
  </Step>
  <Step title="Sign and send the same bytes">
    Sign the path, required headers and exact request body with HMAC-SHA256. Do not reformat the JSON after signing.

    Use a new `X-Nonce` and `X-Timestamp` for every attempt, including retries after a signature error. Check your server IP against the allowlist.

    Use the [signature tool](/environments-and-credentials#sign-requests) to inspect a request before sending it.
  </Step>
  <Step title="Read the business result">
    Read `code` before using `data`. When `code` is `200`, the account query succeeded; it does not prove any payment completed.

    Every JSON business result returns HTTP 200, including errors. An unreadable body or invalid JSON returns HTTP 400 with plain text.

    See [Account details](/api-reference/accounts/get-account-balance) for returned fields and [Authentication errors](/api-reference/error-catalog#authentication-errors) for rejected requests.

    Include the response header `xxx-log-id` in support requests, without your SK or full credentials.
  </Step>
</Steps>

Choose one language. Each example signs and sends the same `{}` body, includes `X-Content-Hash`, and prints the response.

Set `PAGSMILE_TIMEOUT_SECONDS` to a positive integer; the samples default to 30 seconds. Python applies this timeout to blocking socket operations; the other samples use an overall request deadline.

Connection failures and timeouts write errors to standard error and exit unsuccessfully, separately from JSON business results. The samples do not retry automatically.

```bash cURL
# Requires curl, OpenSSL and Python 3. Export PAGSMILE_SK; the HMAC helper reads it from the environment, never command-line arguments. Set PAGSMILE_AK and PAGSMILE_SK. PAGSMILE_BASE_URL defaults to the Sandbox.
BASE_URL="${PAGSMILE_BASE_URL:-https://ebanking-openapi-sandbox.pagsmile.com.br}"
REQ_PATH="/v3/bank_account"
TIMEOUT_SECONDS="${PAGSMILE_TIMEOUT_SECONDS:-30}"
case "$TIMEOUT_SECONDS" in
  ''|*[!0-9]*|0*) echo 'PAGSMILE_TIMEOUT_SECONDS must be a positive integer' >&2; exit 1 ;;
esac
BODY='{}'

# Sign the exact bytes you send. Use a new nonce and timestamp on every attempt.
TS=$(( $(date +%s) * 1000 ))
NONCE=$(openssl rand -hex 16)
HASH=$(printf '%s' "$BODY" | openssl dgst -sha256 -hex | sed 's/^.* //')
STRING_TO_SIGN=$(printf 'POST\n%s\n\ncontent-type:application/json\nx-client-id:%s\nx-content-hash:%s\nx-nonce:%s\nx-timestamp:%s\n%s\n%s\n%s' \
  "$REQ_PATH" "$PAGSMILE_AK" "$HASH" "$NONCE" "$TS" "$HASH" "$TS" "$NONCE")
SIGNATURE=$(printf '%s' "$STRING_TO_SIGN" | python3 -c 'import hashlib, hmac, os, sys; print(hmac.new(os.environ["PAGSMILE_SK"].encode("utf-8"), sys.stdin.buffer.read(), hashlib.sha256).hexdigest())')

curl -sS --connect-timeout "$TIMEOUT_SECONDS" --max-time "$TIMEOUT_SECONDS" -X POST "$BASE_URL$REQ_PATH" \
  -H "Content-Type: application/json" \
  -H "User-Agent: your-app/1.0" \
  -H "X-Client-ID: $PAGSMILE_AK" \
  -H "X-Timestamp: $TS" \
  -H "X-Nonce: $NONCE" \
  -H "X-Content-Hash: $HASH" \
  -H "X-Signature: $SIGNATURE" \
  --data-raw "$BODY"
```

```python Python
# Set PAGSMILE_AK and PAGSMILE_SK. PAGSMILE_BASE_URL defaults to the Sandbox.
import hashlib, hmac, json, os, secrets, sys, time, urllib.error, urllib.request

BASE_URL = os.environ.get("PAGSMILE_BASE_URL", "https://ebanking-openapi-sandbox.pagsmile.com.br")
PATH = "/v3/bank_account"
AK, SK = os.environ["PAGSMILE_AK"], os.environ["PAGSMILE_SK"]
TIMEOUT_SECONDS = int(os.environ.get("PAGSMILE_TIMEOUT_SECONDS", "30"))
if TIMEOUT_SECONDS <= 0:
    sys.exit("PAGSMILE_TIMEOUT_SECONDS must be a positive integer")

payload = {}
body = json.dumps(payload, separators=(",", ":"), ensure_ascii=False).encode("utf-8")

# Sign the exact bytes you send. Use a new nonce and timestamp on every attempt.
ts, nonce = str(int(time.time() * 1000)), secrets.token_hex(16)
content_hash = hashlib.sha256(body).hexdigest()
string_to_sign = "\n".join([
    "POST", PATH, "",
    "content-type:application/json",
    f"x-client-id:{AK}",
    f"x-content-hash:{content_hash}",
    f"x-nonce:{nonce}",
    f"x-timestamp:{ts}",
    content_hash, ts, nonce,
])
signature = hmac.new(SK.encode(), string_to_sign.encode(), hashlib.sha256).hexdigest()

req = urllib.request.Request(BASE_URL + PATH, data=body, method="POST", headers={
    "Content-Type": "application/json",
    "User-Agent": "your-app/1.0",
    "X-Client-ID": AK,
    "X-Timestamp": ts,
    "X-Nonce": nonce,
    "X-Content-Hash": content_hash,
    "X-Signature": signature,
})
try:
    with urllib.request.urlopen(req, timeout=TIMEOUT_SECONDS) as resp:
        print(resp.read().decode("utf-8"))
except urllib.error.HTTPError as err:
    print(err.read().decode("utf-8"))
except (urllib.error.URLError, TimeoutError, OSError) as err:
    print(f"Transport failure: {err}", file=sys.stderr)
    sys.exit(1)
```

```go Go
// Set PAGSMILE_AK and PAGSMILE_SK. PAGSMILE_BASE_URL defaults to the Sandbox.
package main

import (
	"bytes"
	"crypto/hmac"
	"crypto/rand"
	"crypto/sha256"
	"encoding/hex"
	"fmt"
	"io"
	"net/http"
	"os"
	"strconv"
	"strings"
	"time"
)

func main() {
	baseURL := os.Getenv("PAGSMILE_BASE_URL")
	if baseURL == "" {
		baseURL = "https://ebanking-openapi-sandbox.pagsmile.com.br"
	}
	path := "/v3/bank_account"
	ak, sk := os.Getenv("PAGSMILE_AK"), os.Getenv("PAGSMILE_SK")
	timeoutSeconds := 30
	if value := os.Getenv("PAGSMILE_TIMEOUT_SECONDS"); value != "" {
		var err error
		timeoutSeconds, err = strconv.Atoi(value)
		if err != nil || timeoutSeconds <= 0 {
			fmt.Fprintln(os.Stderr, "PAGSMILE_TIMEOUT_SECONDS must be a positive integer")
			os.Exit(1)
		}
	}
	client := &http.Client{Timeout: time.Duration(timeoutSeconds) * time.Second}

	body := []byte(`{}`)

	// Sign the exact bytes you send. Use a new nonce and timestamp on every attempt.
	ts := strconv.FormatInt(time.Now().UnixMilli(), 10)
	nb := make([]byte, 16)
	rand.Read(nb)
	nonce := hex.EncodeToString(nb)
	sum := sha256.Sum256(body)
	contentHash := hex.EncodeToString(sum[:])
	stringToSign := strings.Join([]string{
		"POST", path, "",
		"content-type:application/json",
		"x-client-id:" + ak,
		"x-content-hash:" + contentHash,
		"x-nonce:" + nonce,
		"x-timestamp:" + ts,
		contentHash, ts, nonce,
	}, "\n")
	mac := hmac.New(sha256.New, []byte(sk))
	mac.Write([]byte(stringToSign))
	signature := hex.EncodeToString(mac.Sum(nil))

	req, err := http.NewRequest("POST", baseURL+path, bytes.NewReader(body))
	if err != nil {
		fmt.Fprintln(os.Stderr, "Transport failure:", err)
		os.Exit(1)
	}
```
