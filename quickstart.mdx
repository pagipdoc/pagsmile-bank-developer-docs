## Enable API access

Sign in to the [Banking portal](https://banking.pagsmile.com.br/login) and confirm the account you will use for the integration.

    Account MFA is required before you enable Open API access or manage API keys.

## Send your first signed request

Use `POST /v3/bank_account` to retrieve the target account. Send the empty JSON object `{}`; the request body has no business fields.

<Tabs>
  <Tab title="ACCOUNT" icon="building-columns">
    Use the ACCOUNT AK/SK for your first call. The account comes from the credential, so the samples below omit account-target headers.

    Keep those headers omitted when running the ACCOUNT samples below.
  </Tab>
  <Tab title="USER" icon="user">
    Select an account owned by the USER with both `X-ISPB` and `X-Account-Number`. Include both headers in the signature.

    The samples below do not include these headers. Use the [signature tool](/environments-and-credentials#sign-requests) to sign a USER request.
  </Tab>
  <Tab title="PLATFORM" icon="server">
    <Warning>PLATFORM credentials cannot call this endpoint. Use ACCOUNT credentials, or USER credentials with an authorized account.</Warning>
  </Tab>
</Tabs>

<Steps>
  <Step title="Choose the environment and credentials">
    Start with credentials configured for the Sandbox. The Sandbox base URL is `https://ebanking-openapi-sandbox.pagsmile.com.br`.

    The production base URL is `https://ebanking-openapi.pagsmile.com.br`. Confirm the selected environment before sending a request.
  </Step>
  <Step title="Prepare the sample">
    Set `PAGSMILE_AK` and `PAGSMILE_SK` in your server environment. The examples default to the Sandbox; `PAGSMILE_BASE_URL` overrides the base URL. [Set up API access](/api-access-setup) generates these variables for bash and PowerShell.

    Use the runtime shown in your language tab. Do not put credentials in browser code, source control or support messages.
  </Step>
  <Step title="Sign and send the same bytes">
    Sign the path, required headers and exact request body with HMAC-SHA256. Do not reformat the JSON after signing.

    Use a new `X-Nonce` and `X-Timestamp` for every attempt, including retries after a signature error. Check your server IP against the allowlist.

    Use the [signature tool](/environments-and-credentials#sign-requests) to inspect a request before sending it.
  </Step>
  <Step title="Read the business result">
    Read `code` before using `data`. When `code` is `200`, the account query succeeded; it does not prove any payment completed.

    Every JSON business result returns HTTP 200, including errors. An unreadable body or invalid JSON returns HTTP 400 with plain text.

    See [Account details](/api-reference/accounts/get-account-balance) for returned fields and [Authentication errors](/api-reference/error-catalog#authentication-errors) for rejected requests.

    Include the response header `xxx-log-id` in support requests, without your SK or full credentials.
  </Step>
</Steps>

Choose one language. Each example signs and sends the same `{}` body, includes `X-Content-Hash`, and prints the response.

Set `PAGSMILE_TIMEOUT_SECONDS` to a positive integer; the samples default to 30 seconds. Python applies this timeout to blocking socket operations; the other samples use an overall request deadline.

Connection failures and timeouts write errors to standard error and exit unsuccessfully, separately from JSON business results. The samples do not retry automatically.

<CodeGroup>

```bash cURL
# Requires curl, OpenSSL and Python 3. Export PAGSMILE_SK; the HMAC helper reads it from the environment, never command-line arguments. Set PAGSMILE_AK and PAGSMILE_SK. PAGSMILE_BASE_URL defaults to the Sandbox.
BASE_URL="${PAGSMILE_BASE_URL:-https://ebanking-openapi-sandbox.pagsmile.com.br}"
REQ_PATH="/v3/bank_account"
TIMEOUT_SECONDS="${PAGSMILE_TIMEOUT_SECONDS:-30}"
case "$TIMEOUT_SECONDS" in
  ''|*[!0-9]*|0*) echo 'PAGSMILE_TIMEOUT_SECONDS must be a positive integer' >&2; exit 1 ;;
esac
BODY='{}'

# Sign the exact bytes you send. Use a new nonce and timestamp on every attempt.
TS=$(( $(date +%s) * 1000 ))
NONCE=$(openssl rand -hex 16)
HASH=$(printf '%s' "$BODY" | openssl dgst -sha256 -hex | sed 's/^.* //')
STRING_TO_SIGN=$(printf 'POST\n%s\n\ncontent-type:application/json\nx-client-id:%s\nx-content-hash:%s\nx-nonce:%s\nx-timestamp:%s\n%s\n%s\n%s' \
  "$REQ_PATH" "$PAGSMILE_AK" "$HASH" "$NONCE" "$TS" "$HASH" "$TS" "$NONCE")
SIGNATURE=$(printf '%s' "$STRING_TO_SIGN" | python3 -c 'import hashlib, hmac, os, sys; print(hmac.new(os.environ["PAGSMILE_SK"].encode("utf-8"), sys.stdin.buffer.read(), hashlib.sha256).hexdigest())')

curl -sS --connect-timeout "$TIMEOUT_SECONDS" --max-time "$TIMEOUT_SECONDS" -X POST "$BASE_URL$REQ_PATH" \
  -H "Content-Type: application/json" \
  -H "User-Agent: your-app/1.0" \
  -H "X-Client-ID: $PAGSMILE_AK" \
  -H "X-Timestamp: $TS" \
  -H "X-Nonce: $NONCE" \
  -H "X-Content-Hash: $HASH" \
  -H "X-Signature: $SIGNATURE" \
  --data-raw "$BODY"
```

```python Python
# Set PAGSMILE_AK and PAGSMILE_SK. PAGSMILE_BASE_URL defaults to the Sandbox.
import hashlib, hmac, json, os, secrets, sys, time, urllib.error, urllib.request

BASE_URL = os.environ.get("PAGSMILE_BASE_URL", "https://ebanking-openapi-sandbox.pagsmile.com.br")
PATH = "/v3/bank_account"
AK, SK = os.environ["PAGSMILE_AK"], os.environ["PAGSMILE_SK"]
TIMEOUT_SECONDS = int(os.environ.get("PAGSMILE_TIMEOUT_SECONDS", "30"))
if TIMEOUT_SECONDS <= 0:
    sys.exit("PAGSMILE_TIMEOUT_SECONDS must be a positive integer")

payload = {}
body = json.dumps(payload, separators=(",", ":"), ensure_ascii=False).encode("utf-8")

# Sign the exact bytes you send. Use a new nonce and timestamp on every attempt.
ts, nonce = str(int(time.time() * 1000)), secrets.token_hex(16)
content_hash = hashlib.sha256(body).hexdigest()
string_to_sign = "\n".join([
    "POST", PATH, "",
    "content-type:application/json",
    f"x-client-id:{AK}",
    f"x-content-hash:{content_hash}",
    f"x-nonce:{nonce}",
    f"x-timestamp:{ts}",
    content_hash, ts, nonce,
])
signature = hmac.new(SK.encode(), string_to_sign.encode(), hashlib.sha256).hexdigest()

req = urllib.request.Request(BASE_URL + PATH, data=body, method="POST", headers={
    "Content-Type": "application/json",
    "User-Agent": "your-app/1.0",
    "X-Client-ID": AK,
    "X-Timestamp": ts,
    "X-Nonce": nonce,
    "X-Content-Hash": content_hash,
    "X-Signature": signature,
})
try:
    with urllib.request.urlopen(req, timeout=TIMEOUT_SECONDS) as resp:
        print(resp.read().decode("utf-8"))
except urllib.error.HTTPError as err:
    print(err.read().decode("utf-8"))
except (urllib.error.URLError, TimeoutError, OSError) as err:
    print(f"Transport failure: {err}", file=sys.stderr)
    sys.exit(1)
```

```javascript Node.js
// Node.js 18+. Save as pagsmile-request.mjs and run: node pagsmile-request.mjs.
// Set PAGSMILE_AK and PAGSMILE_SK. PAGSMILE_BASE_URL defaults to the Sandbox.
import { createHash, createHmac, randomBytes } from "node:crypto";

const BASE_URL = process.env.PAGSMILE_BASE_URL ?? "https://ebanking-openapi-sandbox.pagsmile.com.br";
const PATH = "/v3/bank_account";
const { PAGSMILE_AK: AK, PAGSMILE_SK: SK } = process.env;
const TIMEOUT_SECONDS = Number(process.env.PAGSMILE_TIMEOUT_SECONDS ?? "30");
if (!Number.isSafeInteger(TIMEOUT_SECONDS) || TIMEOUT_SECONDS <= 0) {
  throw new Error("PAGSMILE_TIMEOUT_SECONDS must be a positive integer");
}

const body = JSON.stringify({});

// Sign the exact bytes you send. Use a new nonce and timestamp on every attempt.
const ts = String(Date.now());
const nonce = randomBytes(16).toString("hex");
const contentHash = createHash("sha256").update(body, "utf8").digest("hex");
const stringToSign = [
  "POST", PATH, "",
  "content-type:application/json",
  `x-client-id:${AK}`,
  `x-content-hash:${contentHash}`,
  `x-nonce:${nonce}`,
  `x-timestamp:${ts}`,
  contentHash, ts, nonce,
].join("\n");
const signature = createHmac("sha256", SK).update(stringToSign, "utf8").digest("hex");

try {
  const res = await fetch(BASE_URL + PATH, {
    method: "POST",
    signal: AbortSignal.timeout(TIMEOUT_SECONDS * 1000),
    headers: {
      "Content-Type": "application/json",
      "User-Agent": "your-app/1.0",
      "X-Client-ID": AK,
      "X-Timestamp": ts,
      "X-Nonce": nonce,
      "X-Content-Hash": contentHash,
      "X-Signature": signature,
    },
    body,
  });
  console.log(await res.text());
} catch (err) {
  console.error("Transport failure:", err.message);
  process.exitCode = 1;
}
```
